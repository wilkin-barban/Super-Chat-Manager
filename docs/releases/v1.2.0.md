# Super Chat Manager v1.2.0

Released 2026-11-08 · GPL-3.0-or-later

## Highlights

- Rebranded from **LiveChat Pro** to **Super Chat Manager**; official repository: `https://github.com/wilkin-barban/Super-Chat-Manager`.
- Durable chat session state: sessions persist and reconcile across reconnects and restarts.
- Hardened lifecycle and presence recovery for multi-client and reconnect scenarios.
- Bounded, security-reviewed remote ingestion for RAG, including request-secret redaction and GitHub snapshot limits.
- Modularized admin route families, tracked-test/repository hygiene, Node 24 SQLite fix, and Docker image/container naming updates.
- The RAG administration, deduplication, URL revision publishing, configurable master prompt and responsive admin features from 1.1.0 remain available.

## Install and upgrade

- **Docker:** `docker pull ghcr.io/wilkin-barban/super-chat-manager:1.2.0` (or `:latest`), then recreate the containers.
- **Source:** Node.js >= 24, `npm ci`, `node setup.js`, or `docker compose up -d --build`.
- Legacy identifiers (`data/livechat.db`, `livechat_data`, `lcp`, `LIVECHAT_*`, `lchat_sid`) are preserved; no data migration is required.
